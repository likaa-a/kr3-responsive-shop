# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

`ATELIER 12` — адаптивный учебный интернет-магазин дорогих механических часов. В проекте использованы только HTML, CSS и JavaScript без Bootstrap. Визуальное направление — официальный деловой стиль: крупная предметная фотография, спокойная песочно-графитовая палитра, строгая типографика и акцент на частной консультации.

Сайт включает пять страниц:

- главная с интерактивным выбором модели;
- каталог с работающей фильтрацией;
- страница модели с таблицей характеристик и модальным окном;
- форма заявки с доступной валидацией;
- контакты.

Названия, адрес, цены и характеристики являются демонстрационным содержанием учебного проекта. Оплата и настоящий backend не подключены.

## Практическая работа №12

Выполнено:

## Практическая работа №13

Тема: «A11y-аудит и обеспечение доступности. Использование Lighthouse и анализ проблем доступности».

Выполнено:

- проверена семантическая структура всех страниц;
- на каждой странице используется один `h1` и логичная иерархия заголовков;
- добавлена ссылка пропуска к основному содержимому;
- текущий пункт навигации отмечен `aria-current="page"`;
- мобильное меню управляется настоящей кнопкой с `aria-expanded`;
- добавлен хорошо заметный `:focus-visible`;
- у смысловых изображений есть точные `alt`-описания;
- все поля формы связаны с `label`;
- сообщения об ошибках связаны с полями через `aria-describedby`;
- `aria-invalid` появляется только после фактической ошибки;
- действия реализованы через `button`, переходы — через `a`;
- таблица имеет `caption`, `th` и атрибуты `scope`;
- модальное окно реализовано через `dialog`, имеет заголовок и доступную кнопку закрытия;
- добавлена поддержка `prefers-reduced-motion`;
- контраст текста, кнопок, ошибок и фокуса усилен;
- проведена ручная проверка клавиатурной навигации;
- Lighthouse-отчёт сохранён в папке `lighthouse/`.

## Lighthouse

Проверены страницы:

- `index.html`;
- `catalog.html`;
- `order.html`.

Отчёты и итоговая сводка находятся в папке `lighthouse/`.

## Исправления доступности

В исходном учебном проекте отсутствовали skip-link и отдельный Mobile First-файл, изображения заменялись эмодзи, а часть адаптивных правил использовала только `max-width`. В новой версии добавлены настоящие изображения с альтернативным текстом, единый видимый фокус, семантические области, доступная форма с сообщениями об ошибках, клавиатурно доступный `dialog`, мобильная навигация и горизонтально прокручиваемая таблица с доступным названием области.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить простой HTTP-сервер из папки проекта:

```bash
python -m http.server 8080
```

После запуска сайт доступен по адресу `http://localhost:8080/`.
