# Шаблоны Pull Request

GitHub remote не подключён к локальному проекту, поэтому ниже подготовлены тексты для создания двух Pull Request после `git push`.

## Add responsive layout styles

Ветка: `feature/responsive-layout` → `main`

### Что сделано

- Создан проект `kr3-responsive-shop`.
- Добавлен файл `css/responsive.css`.
- Проверен `viewport` на всех страницах.
- Реализована Mobile First-вёрстка.
- Адаптированы навигация, hero, карточки, каталог, форма, таблица и модальное окно.
- Добавлены `picture`, `srcset`, `sizes` и ленивые изображения.

### Как проверить

- Открыть `index.html`.
- Проверить ширины 360, 430, 768, 1024 и 1440 px.
- Проверить отсутствие горизонтального скролла.
- Открыть каталог, страницу модели и форму.

## Improve accessibility and add Lighthouse report

Ветка: `feature/a11y-lighthouse-audit` → `main`

### Что сделано

- Проверена семантическая структура страниц.
- Добавлены skip-link, видимый фокус и `aria-current`.
- Проверены изображения, формы, кнопки, ссылки, таблица и `dialog`.
- Добавлены связанные сообщения об ошибках формы.
- Выполнен Lighthouse-аудит трёх страниц.
- Добавлены HTML- и JSON-отчёты Lighthouse.
- Обновлён README.

### Как проверить

- Пройти все страницы клавишей Tab.
- Проверить мобильное меню и модальное окно.
- Заполнить форму с ошибками и без ошибок.
- Открыть файлы в папке `lighthouse/`.
